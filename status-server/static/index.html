Как считается доступность

Мы проверяем серверы каждую минуту. Если две проверки подряд не проходят, отмечаем сбой. Когда работа восстанавливается, запись обновляется автоматически.

Процент показывает, какую часть выбранного времени сервер работал без сбоев. Периоды без наблюдений отмечены серым и не влияют на результат. Плановые работы отмечаются отдельно и не скрывают фактическую недоступность.

Время указано по Москве. Доступность из вашей сети может отличаться.
